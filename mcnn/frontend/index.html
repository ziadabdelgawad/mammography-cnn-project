Project workflow

How the project is built

01Dataset

CBIS-DDSM is prepared with patient-level train, validation and held-out test splits.

02Experiments

Baseline, regularised and VGG16 transfer-learning CNNs are trained and compared.

03Evaluation

Accuracy, sensitivity, specificity, precision, F1, ROC-AUC and PR-AUC are measured.

04Deployment

The model is selected using validation ROC-AUC only and then loaded by this website.
